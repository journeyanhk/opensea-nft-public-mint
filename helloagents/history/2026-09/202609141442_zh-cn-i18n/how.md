# 技术设计: 越南语文案翻译为简体中文

## 技术方案
### 核心技术
- TypeScript 5.3 / Node.js 18+；不引入任何新依赖
- 纯字符串替换，不改动类型、控制流、正则结构（除测试断言文案）

### 实现要点
- 逐文件替换越南语字符串为简体中文，保留变量插值（`${...}`）与 ANSI 颜色调用
- 术语统一：Public → 公售/Public、Allowlist → Allowlist、WL FCFS 保留、gas/wei/gwei 保留、SeaDrop 保留、sequencer 保留
- 时间文案：`VN (UTC+7)` → `越南时间 (UTC+7)`；`vi-VN` locale 与 `Asia/Ho_Chi_Minh` 时区**保持不变**（不改变行为）
- `prompt.ts` 的 askYesNo 输入识别：越南语 `có/không` → 中文 `是/否`（`y/yes/n/no` 保留）
- `tests/stage-wait.cjs` 的正则 `/Không có vòng/` → 与新中文错误消息匹配

## 架构设计
无架构变更（纯文案层）。

## 架构决策 ADR
### ADR-1: 文案中文化但不改时区语义
**上下文:** 工具按越南时间（UTC+7）展示与输入开售时间，用户要求翻译文案但"其他都先不用改"。
**决策:** 保留 UTC+7 时间语义与 `vi-VN` locale 格式化，仅将展示文字翻译为中文（"越南时间 (UTC+7)"）。
**理由:** 避免翻译任务意外改变发送时机行为；时区切换属于独立需求，可后续单独提出。
**替代方案:** 同时切换为北京时间 UTC+8 → 拒绝原因: 超出"仅翻译文案"的范围，且会改变用户输入时间的解释。
**影响:** 中文界面下时间仍为越南时区，需在 README 中说明。
